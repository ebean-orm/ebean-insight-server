# Development documentation

These guides describe how to modify and maintain Ebean Insight. They are
separate from the surrounding `docs/` pages, which describe installing,
deploying, and using the product.

## Guides

- [`local-server.md`](local-server.md) - build, start, stop, restart, seed, and
  inspect a local server.
- [`ui.md`](ui.md) - trace UX requests through controllers, templates, CSS,
  JavaScript, and Chart.js payloads.
- [`demo-data.md`](demo-data.md) - maintain and run the repeatable UX seed.
- [`testing.md`](testing.md) - run focused Java tests, builds, syntax checks,
  and manual browser validation.
- [`troubleshooting.md`](troubleshooting.md) - diagnose startup, stale assets,
  missing data, and chart serialization problems.

Agent-specific repository rules are in the root [`AGENTS.md`](../../AGENTS.md).
